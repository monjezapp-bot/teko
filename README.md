# Teko — خطوات التشغيل
1. Supabase (مشروع Teko): SQL Editor → شغّل `schema.sql` كاملاً، ثم فعّل سطر المفتاح السري (ADMIN 1) بعد ما تحط مفتاحك.
2. عدّل `config.js` (الـ URL والـ anon key). ده الملف الوحيد اللي بتعدّله.
3. GitHub: repo جديد → ارفع كل الملفات → Settings → Pages → Deploy from branch (main / root).
4. طيارين: `https://USER.github.io/REPO/`
   مشرف: `https://USER.github.io/REPO/supervisor.html#k=مفتاحك` (افتحه مرة على كل جهاز).
